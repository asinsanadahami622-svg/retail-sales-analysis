# Retail Sales Analysis Dashboard

## Project Overview
This project analyzes sample retail sales data using Excel, SQL Server, and Power BI. The goal is to understand sales performance, customer demographics, and product category performance.

## Tools & Technologies
- Microsoft Excel – Data cleaning and preparation
- SQL Server Management Studio (SSMS) – Data analysis using SQL
- Microsoft Power BI – Dashboard development
- DAX – Creating measures and calculated columns

## Dataset Information
- Total Records: 1,000
- Total Columns: 9
- Data Period: 2023
- Product Categories: Clothing, Electronics, Beauty

This is sample retail data used for a Sri Lankan retail business analysis scenario. It is not verified data from an actual Sri Lankan company.

## Key Findings
- Total Revenue: Rs. 456,000
- Total Transactions: 1,000
- Total Customers: 1,000
- Highest Revenue Category: Electronics (Rs. 156,905)
- Female Customer Revenue: Rs. 232,840
- Male Customer Revenue: Rs. 223,160
- Highest Revenue Age Group: 46–55 (Rs. 100,690)

## Dashboard Features
- Total Revenue KPI
- Total Transactions KPI
- Total Customers KPI
- Sales by Product Category
- Monthly Sales Trend
- Sales by Gender
- Sales by Age Group
